# T-15: Users are view-only, lock every edit action

## User story

As an Admin, I want Users to be view-only so that only I can change business data.

## Acceptance criteria

- [ ] Hide or disable add, edit, delete and import buttons for Users
- [ ] The API rejects writes from Users

## Dependencies

- T-14 Enforce permissions in the UI and the API

## Size

S (1 effort point). Priority P0.
