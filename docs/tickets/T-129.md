# T-129: Multi-language (i18n): Vietnamese (VI) and English (EN)

## User story

As any user, I want the app in Vietnamese or English so that I can use it in the language I prefer.

## Acceptance criteria

- [ ] All text, dates, numbers and money follow the language
- [ ] The app opens in English; Vietnamese is available through the toggle
- [ ] No hard-coded text in code
- [ ] Built with `next-intl`; only English (`en`) and Vietnamese (`vi`) exist

## Dependencies

- T-06 App shell and menu

## Size

M (3 effort points). Priority P1.
