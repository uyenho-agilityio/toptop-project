# T-21: Period filter: Daily, Weekly, Monthly

## User story

As any user, I want Daily, Weekly and Monthly buttons shared across modules so that every screen shows the same period compared with the one before it.

## Acceptance criteria

- [ ] Three quick buttons shared by every module
- [ ] Each period compares with the one right before, of the same length: Daily is today, Weekly is the last 7 days, Monthly is the 1st of the month to today
- [ ] The compared period is named once under the greeting

## Dependencies

- T-06 App shell and menu

## Size

M (3 effort points). Priority P0.
