# T-11: Admin invites a User by email

## User story

As an Admin, I want to invite a User by email so that my team can look at the business data.

## Acceptance criteria

- [ ] Enter email; the invited person becomes a User with no modules
- [ ] Create the invitation link for the Admin to copy and send (the app does not email it); status Invited; revoke an invitation
- [ ] The link is single-use and expires after 7 days
- [ ] The Google account that accepts must have the invited email
- [ ] The invitation token is random (at least 32 bytes) and stored only as a hash; creating invitations is rate limited (20 per hour per Admin)

## Dependencies

- T-09 Sign in with Google

## Size

M (3 effort points). Priority P0.
