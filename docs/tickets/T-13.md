# T-13: Grant access per module

## User story

As an Admin, I want to grant each User View access per module so that they see only what they need.

## Acceptance criteria

- [ ] One level per User per module: View or No Access
- [ ] A new User has no modules until an Admin assigns them; an invited Admin has all modules
- [ ] Changes take effect immediately

## Dependencies

- T-11 Admin invites a User by email

## Size

M (3 effort points). Priority P0.
