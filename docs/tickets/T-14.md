# T-14: Enforce permissions in the UI and the API

## User story

As the platform, I need permissions enforced in the UI and in every API so that a User can never reach data they were not granted.

## Acceptance criteria

- [ ] Route guards in the UI, permission checks on every API
- [ ] Cards, charts, reports and exports use only the data of granted modules
- [ ] Ask AI is Admin only: Users have no Ask AI and the API rejects them
- [ ] Every API route and server action has an explicit permission check (deny by default) and a validation schema
- [ ] Responses carry the basic security headers (Q-SEC-7)

## Dependencies

- T-13 Grant access per module

## Size

M (3 effort points). Priority P0.
