# T-122: A single System Admin set by server configuration

## User story

As the platform owner, I want a single System Admin set by server configuration so that platform control stays with one trusted person.

## Acceptance criteria

- [ ] System Admin email set in server configuration (SYSTEM_ADMIN_EMAIL)
- [ ] That account can sign in without an invitation and becomes System Admin
- [ ] When the configured email changes, the previous System Admin loses access immediately
- [ ] No screen to create more

## Dependencies

- T-09 Sign in with Google

## Size

S (1 effort point). Priority P0.
