# T-25: Shared metrics engine

## User story

As the platform, I need one metrics engine so that every module shows numbers that agree with each other.

## Acceptance criteria

- [ ] One place computes gross sales, net revenue, cost of goods, costs and profit
- [ ] Every module reads from it and does not recalculate
- [ ] Tested against a sample dataset

## Dependencies

- T-01 Design the extensible data model

L (5 effort points). Priority P0.
