# T-06: App shell and menu

## User story

As any signed-in user, I want a clear app shell and menu that shows only what I may open so that I can move around the app.

## Acceptance criteria

- [ ] Sidebar with 8 modules, AI Assistant (Admin only), Settings
- [ ] Menu hides modules the User cannot access
- [ ] Header with page title and filters
- [ ] Tablet and phone: drawer menu
- [ ] The UI uses one set of semantic color tokens, each with a light and a dark value, defined in `src/themes/globals.css` (`@theme`); no file hard-codes a color. T-06 is the first UI ticket, so every later UI ticket uses these tokens, and T-06 blocks T-130 Light and dark themes (values in [m1-i18n-theme-seed.md](../spec/m1-i18n-theme-seed.md), "Color tokens").
