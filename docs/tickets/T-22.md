# T-22: Custom date range with a calendar popup

## User story

As any user, I want to pick my own date range in a calendar popup so that I can look at any period I need.

## Acceptance criteria

- [ ] Pick start and end dates in a calendar popup
- [ ] While Custom is active, the three quick buttons stop applying
- [ ] Pressing one of them returns to quick mode

## Dependencies

- T-21 Period filter: Daily, Weekly, Monthly

## Size

M (3 effort points). Priority P0.
