# T-17: System Admin has no automatic access to finance and tax

## User story

As an Admin, I want the System Admin to have no automatic access to my finance and tax data so that my business information stays private.

## Acceptance criteria

- [ ] System Admin cannot read a Business’s Finance or Tax data
