# T-04: “Not available yet” convention instead of 0

## User story

As a seller, I want missing data to read “not available yet” instead of 0 so that I am never misled by a made-up zero.

## Acceptance criteria

- [ ] Shared component shows “not available yet” when data has not been entered or synced
- [ ] A real 0 still shows as 0
- [ ] Applies to cards, tables and charts

## Dependencies

None.

## Size

S (1 effort point). Priority P0.
