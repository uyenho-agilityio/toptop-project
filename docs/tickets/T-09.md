# T-09: Sign in with Google

## User story

As any user, I want to sign in with Google so that I can reach TopTop without a new password.

## Acceptance criteria

- [ ] Sign in, sign out, keep the session
- [ ] Sign-in works only for an invited email; a Google account with no invitation is blocked
