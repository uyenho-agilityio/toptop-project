# T-07: Metric card component

## User story

As the platform, I need one metric card component so that every module shows its key numbers the same way.

## Acceptance criteria

- [ ] Label, value, sub line, change versus previous period, one-line explanation
- [ ] Supports the “not available yet” state
- [ ] Clicking a card opens its module

## Dependencies

- T-04 “Not available yet” convention instead of 0
- T-05 Format money, numbers and dates
