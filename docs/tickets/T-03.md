# T-03: Store and show the source of every record

## User story

As an Admin, I want every record to show where it came from (platform API, import file or manual entry) so that I can trust the numbers.

## Acceptance criteria

- [ ] Each record has a source: platform API, import file or manual entry
- [ ] Show a source label in tables and detail views
