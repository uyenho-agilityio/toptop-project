# T-10: Notice for people without access

## User story

As a person without an invitation, I want to be told I have no access yet so that I know to contact an Admin.

## Acceptance criteria

- [ ] An account without an invitation (or a locked account) is blocked and cannot reach any data
- [ ] Block every other API
- [ ] A person with no invitation sees a notice that they have no access yet and should contact an Admin

## Dependencies

- T-09 Sign in with Google

## Size

S (1 effort point). Priority P0.
